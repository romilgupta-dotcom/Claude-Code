# Claude-Code

A Python project.

## Getting started

```bash
git clone git@github.com:romilgupta-dotcom/Claude-Code.git
cd Claude-Code
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
```

Install dependencies once a `requirements.txt` or `pyproject.toml` is added:

```bash
pip install -r requirements.txt
```
